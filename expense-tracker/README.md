# Expense Tracker

A React app for tracking personal income and expenses.

## Features
- Add income and expense transactions
- Categorize and date transactions
- Calculate balance, income and spending totals
- Filter by transaction type
- Delete transactions
- Save data in localStorage

## Run
```bash
npm install
npm run dev
```

Tech: React, Vite, JavaScript, CSS, localStorage. Data is stored in the current browser only.
